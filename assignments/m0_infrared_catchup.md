1. **Project board access** — You can see tasks and move cards
1. **First contribution** — Even a documentation fix or typo correction counts

*When in doubt, ship something small. Momentum matters more than magnitude.*

-----

## THE SACRED FLOW™ (Your Git Survival Pattern)

```
Issue → Branch → Code → Pull Request → Review → Merge
```

Every contribution follows this path. No exceptions. No direct commits to main.

**Branch naming:** `feature/citizen-[your-id]-[what-youre-doing]`

**Commit messages:** Present tense, clear purpose. “Add user login validation” not “added stuff”

Your teammates will review your PRs. This is how learning transfers. Review theirs in return—you’ll understand the codebase faster by reading than by guessing.

-----

## ASKING QUESTIONS (This Is Your Job Right Now)

You have mass permission to ask:

- “What does this part of the codebase do?”
- “Why did we make this architectural choice?”
- “Can someone pair with me on my first task?”
- “I’m stuck on X—who knows this area best?”

**Ask in public channels, not DMs.** Your question probably helps someone else. The answer definitely will.

Questions you ask now prevent mistakes that cost the team hours later. Asking is contribution.
