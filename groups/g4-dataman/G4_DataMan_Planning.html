The Product
DataMan

A web-based math challenge platform. Users log in, pick a game mode, solve problems, and see their performance tracked over time. Problems get harder or easier based on how the user is doing.

┌──────────────────────────────────────────────────────────┐ │ THE CORE LOOP │ │ │ │ Log In ──→ Pick a Mode ──→ Solve Problems │ │ ↑ │ │ │ │ ▼ │ │ │ See Your Score │ │ │ │ │ │ └──── Come Back Tomorrow ◄─────┘ │ │ │ │ (difficulty adapts each time) │ └──────────────────────────────────────────────────────────┘

The original Dataman was a Texas Instruments calculator from 1977. Shaped like a robot. Had math games for kids. You built console versions of some of these in CTS 285. Now you're building the web version.

Four Game Modes
Known mechanics. Web-scale.
Mode 1 · Solo
Answer Checker
An equation appears with an answer. Is it right or wrong? Fast, binary, builds number sense.
24 + 17 = 41 [✓ Right] [✗ Wrong]
Mode 2 · Solo
Number Guesser
DataMan picks a secret number. You guess. Higher or lower hints. Fewest guesses wins.
"I'm thinking of 1-100" → 50 → "Higher!"
Mode 3 · Solo
Speed Round
60-second countdown. Rapid-fire problems. How many can you get? Beat your record.
⏱ 47s | 6 × 7 = [__] | Score: 12
Mode 4 · Solo
Fill It In
An equation has a blank — a missing number or operator. Find the missing piece.
___ + 5 = 12 24 ___ 6 = 4

Some of you built Answer Checker and Number Guesser as console apps in CTS 285. The logic is the same. The challenge is making it persistent, adaptive, and web-accessible.

An Important Distinction
User Stories ≠ Technical Requirements
USER STORY

Something a user can do with your product.

"As a user, I can play Answer Checker and see my score saved." → The user cares about this. → This is in the demo.
TECHNICAL REQUIREMENT

Something the team needs to do to make the product work.

"Repository created with branch protection on main." → The user doesn't know. → This enables the work.
Both go on your sprint board. Both get branches and PRs. The difference matters because it trains you to think about who benefits from each piece of work.
