# The Sacred Workflow Revisited

TO DO A THING:
- Make an issue. 
- Make a branch to write code in.
- Start a draft Pull Request to start taking notes about
- Write and Test your code. 
- Write up the final Pull Request
- Get it reviewed, and merge it ("Let's take it to main")

That's how you cook *one burger* in our kitchen. (The "Solo Burger" assignment is practice for this.)

How do we handle the lunch hour? With a GitHub Project, within which we use this workflow!
